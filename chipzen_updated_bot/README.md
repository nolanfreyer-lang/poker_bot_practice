# UPDATED_OPTIMAL for Chipzen

Generated by `NLH_Poker_Bot/build_chipzen.py`. Do not edit `bot.py` by hand: change the
strategy in `NLH_Poker_Bot`, then rebuild from a clone of the SDK:

```bash
git clone https://github.com/chipzen-ai/chipzen-sdk.git
cd NLH_Poker_Bot
python3 build_chipzen.py --sdk /path/to/chipzen-sdk --bot UPDATED_OPTIMAL
```

## Build the upload file (needs Docker)

```bash
pip install chipzen-bot
chipzen-sdk validate . --check-connectivity
docker build --platform linux/amd64 -t updated-optimal:v1 .
docker run --rm --entrypoint sh updated-optimal:v1 -c "ls /bot/"
docker save updated-optimal:v1 | gzip > updated-optimal.tar.gz
ls -lh updated-optimal.tar.gz
```

`ls /bot/` should show a compiled `bot.cpython-312-...so` and no `bot.py`. The file must
be under 250 MB compressed. Upload it through the Chipzen developer site.

ICM is off, because Chipzen matches have no payout ladder to model, so numpy is
not needed. Bluff tracking resets at the start of each match.
